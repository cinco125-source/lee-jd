_Effective date: November 20, 2026_

This policy covers **Pulse**, a personal dashboard built and operated by Jayden Dongwoo Lee for his own use. Pulse is not offered to the public. The only Google accounts connected to it belong to the operator.

### What Google data Pulse accesses

- **Google Calendar** (`calendar`): reads the operator's calendar events to show the day's schedule, and creates or updates events when the operator asks for it.
- **Google Drive** (`drive.file`, `drive.readonly`): reads the operator's own documents and saves files that Pulse creates for the operator.

Pulse does not request access to Gmail, contacts, photos, or location.

### How the data is used

The data is used only to provide the dashboard and assistant features to the operator himself: showing his schedule, reminding him of meetings, and preparing documents he asks for. AI assistant services that the operator uses may process this data only to carry out his own requests.

Pulse does not sell Google user data, does not share it with third parties for advertising, and does not use it to train general AI or machine learning models.

### Storage and security

Calendar events are copied into a private database so the dashboard loads quickly. The dashboard is protected by a login, and access tokens are kept as server secrets. They are not published anywhere.

### Google API Services User Data Policy

Pulse's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

### Removing access and deleting data

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Copied calendar data is deleted on request.
